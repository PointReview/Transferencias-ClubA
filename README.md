# Club A Sex Shop — datos para transferir

Sitio estático listo para publicar con GitHub Pages. Incluye botones para copiar cada dato, copiar todos los datos de una cuenta y contacto por WhatsApp.

## Publicarlo en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí todo el contenido de esta carpeta, sin cambiar la estructura.
3. En el repositorio, abrí **Settings > Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná la rama `main` y la carpeta `/(root)`.
5. Guardá. GitHub mostrará la dirección pública del sitio en unos minutos.

El archivo principal es `index.html`. No requiere instalación, compilación ni servidor.
